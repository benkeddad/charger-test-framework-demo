HOW TO RUN LOCALLY
==================

Set up environment:
  set PYTHONPATH=src

Simulate PR smoke tests:
  ruff check .
  pytest -m smoke -v

Simulate nightly full tests:
  pytest -v
  python tools/trace_report.py --fail-on-uncovered
  python tools/flake_check.py 5

Check requirement coverage:
  python tools/trace_report.py
  # Edit trace.md to see requirement matrix
